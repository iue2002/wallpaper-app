# 小K壁纸应用

小K壁纸是一款功能丰富的壁纸应用，支持多种壁纸源，包括Bing、Unsplash、Pexels等。

## 功能特性

- 📱 多种壁纸源选择
- 🔄 定时轮换壁纸
- 🚀 开机自启
- 🖼️ 壁纸预览
- 💾 本地缓存
- 🎨 深色模式支持

## 系统要求

- Windows 10/11
- .NET 8.0 Runtime

## 安装方法

### 方法一：使用MSI安装包
1. 从 [Releases](https://github.com/iue2002/wallpaper-app/releases) 页面下载最新的MSI安装包
2. 双击运行安装包，按照提示完成安装

### 方法二：从源码构建
1. 克隆仓库：`git clone https://github.com/iue2002/wallpaper-app.git`
2. 打开 `App1.sln` 解决方案
3. 构建解决方案：`Build > Build Solution`
4. 运行应用：`Debug > Start Without Debugging`

## 壁纸源

- Unsplash

- 360壁纸
